# civita-computational-data-submission

Part of CIVITA, the Computational Infrastructure for Validation, Integration, Testing, and Assessment.

Contributor-facing application for submitting computational models, simulation configurations, numerical results, and associated metadata to the CIVITA scientific repository.

This component is under development. Application development will follow the definition of the computational database schema.
